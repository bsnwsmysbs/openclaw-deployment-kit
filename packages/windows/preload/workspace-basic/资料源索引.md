# OpenClawMeeting 基础版资料源索引

本索引用于基础版安装，指导用户放置资料和查找产出。

## 桌面目录结构

```text
桌面\龙虾工作台
  01-输入资料
    综合资料源
  02-输出成果
    通用成果
  03-人工复核
  04-历史归档
```

## 默认资料入口

| 类型 | 默认资料目录 | 说明 |
| --- | --- | --- |
| 综合资料源 | `桌面\龙虾工作台\01-输入资料\综合资料源` | 放置用户希望龙虾读取、总结、问答或整理的资料 |
| 通用成果 | `桌面\龙虾工作台\02-输出成果\通用成果` | 保存生成的报告、说明、表格、清单和操作 notes |

## 建议文件命名

- `2026-06-情况说明-主题.docx`
- `2026-06-资料汇总-主题.xlsx`
- `2026-06-会议材料-主题.docx`
- `2026-06-制度文件-主题.pdf`

## 用户提问示例

- `请总结综合资料源里的资料。`
- `请根据这份文件起草一份情况说明。`
- `请把综合资料源里的事项整理成表格。`
- `请告诉我当前资料应该放在哪里。`
