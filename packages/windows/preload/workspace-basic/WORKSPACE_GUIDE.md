# OpenClawMeeting 基础版使用导航

当前安装为基础版，不预置 7 个业务 Skill。

把资料放到桌面的中文工作台目录，然后在聊天窗口直接用自然语言提问。

默认工作台：

```text
桌面\龙虾工作台
```

## 资料放置

- 通用资料放到：`桌面\龙虾工作台\01-输入资料\综合资料源`
- 生成结果默认放到：`桌面\龙虾工作台\02-输出成果\通用成果`

## 基础功能

| 功能 | 示例提问 |
| --- | --- |
| 文件问答 | 请根据综合资料源里的文件回答这个问题。 |
| 文档总结 | 请总结综合资料源里的这份报告。 |
| 材料起草 | 请帮我起草一份情况说明。 |
| 表格整理 | 请把这些事项整理成检查表。 |
| 操作说明 | 请告诉我资料应该放在哪里。 |

## 输出格式

- 报告、说明、总结：`.docx`
- 台账、清单、表格：`.xlsx`
- 汇报材料：`.pptx`
- 简短操作说明：`.txt`

默认不输出 `.md` 文件，方便用户直接用 WPS 打开。

## 说明

如果需要会议督办、合同风险审查、政策简报、人力绩效、战略执行、员工行为、管理优化等 7 个业务能力，需要使用业务增强版安装，或由交付人员后续补装业务 Skill。
