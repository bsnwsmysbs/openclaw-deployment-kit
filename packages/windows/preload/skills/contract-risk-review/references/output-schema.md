# Output Schema

## Risky Clause List

| Column | Notes |
| --- | --- |
| 风险编号 | Use `HT-YYYYMMDD-001`. |
| 合同名称 | Source contract. |
| 条款位置 | Clause number or heading. |
| 原条款摘要 | Short summary, not long quotation. |
| 风险类型 | Use review dimensions. |
| 风险等级 | 高/中/低. |
| 风险说明 | Why it matters. |
| 法律/制度依据 | Local law file and article if available. |
| 修改建议 | Draft amendment idea. |
| 需复核问题 | Concrete question for legal/business reviewer. |

## Report Structure

1. 审查范围
2. 合同基本信息
3. 总体风险判断
4. 重点风险条款
5. 修改建议
6. 需人工复核事项
7. 引用依据与附件
