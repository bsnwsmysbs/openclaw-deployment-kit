# Writing Style

## Report Structure

Use this structure for `会议督办闭环报告.docx`:

1. 基本情况
2. 督办事项总体情况
3. 已闭环事项
4. 未闭环及风险事项
5. 需人工复核事项
6. 下一步建议
7. 附件清单

## Tone

Use formal Chinese management writing. Be direct, evidence-based, and cautious.

Prefer:

- `根据已提供材料，初步判断...`
- `建议进一步核实...`
- `该事项已有阶段性进展，但尚缺少...`
- `暂不建议直接认定为已闭环。`

Avoid:

- Unsupported certainty.
- Legal final opinions.
- Personnel punishment suggestions.
- `保证`, `必然`, `已经完全无风险`.

## Citation

For every key conclusion, cite source material by file name and section/page if available. If no exact page exists, cite the paragraph heading or closest text anchor.

## Executive Summary

Keep the first page short:

- Total task count.
- Closed count.
- Not closed count.
- High-risk count.
- Items requiring human review.
- Top three next actions.
