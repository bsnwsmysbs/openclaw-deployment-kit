# Extraction Guidelines

## Source Priority

1. Human correction files in `05-人工修正`.
2. Explicit leadership requirements or signed/issued meeting minutes.
3. Meeting records and notes.
4. Supervision feedback.
5. Completion materials.

When sources conflict, keep both facts, follow higher priority for the draft judgment, and add the item to `人工复核清单`.

## Task Extraction

Extract a task when the text contains an actionable requirement with an object and direction, such as:

- Require a department to complete, promote, report, rectify, coordinate, inspect, or submit something.
- Assign responsibility, deadline, deliverable, risk disposal, or follow-up action.
- Mention leadership instruction that implies a trackable task.

Do not create a task from general background, meeting attendance, broad slogans, or descriptive facts.

## Matching Feedback To Tasks

Match feedback by:

- Same or similar task title.
- Same responsible unit.
- Same project/business object.
- Same deadline or reporting period.
- Direct reference to meeting name, decision number, or leadership requirement.

If one feedback paragraph may cover multiple tasks, split the evidence and cite the same source for each matched item. If matching confidence is low, set `需人工确认`.

## Evidence Rules

Completion evidence should show a result, not only activity. Prefer files or statements showing approval, issued document, accepted deliverable, completed整改, signed confirmation, data result, or explicit closure feedback.

If evidence only says `正在推进`, `已沟通`, `已安排`, `持续跟进`, or `后续落实`, do not mark as `已闭环`.
