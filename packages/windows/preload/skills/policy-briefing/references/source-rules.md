# Source Rules

Prefer official and primary sources:

- 国务院、国家发展改革委、国家能源局、生态环境部、财政部、市场监管总局等官网。
- 省市政府、能源主管部门、发改委等官网。
- 官方发布平台和政策原文页面。

For `最新`, `近期`, `今日`, `本周`, or similar requests, browse current sources and record access date.

Each policy item must include:

- 标题
- 发布机关
- 发布日期
- 原文链接
- 摘要
- 与综合能源管理的关系
- 建议关注动作
