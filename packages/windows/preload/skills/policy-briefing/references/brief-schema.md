# Brief Schema

## Policy Link List

| Column | Notes |
| --- | --- |
| 序号 | Sequential. |
| 政策标题 | Exact title. |
| 发布机关 | Official agency. |
| 发布日期 | Use exact date. |
| 原文链接 | Direct source URL. |
| 相关领域 | 综合能源、双碳、电力、节能、储能、市场化交易等. |
| 影响等级 | 高/中/低. |
| 关注建议 | Business-oriented next action. |

## Brief Structure

1. 本期政策概览
2. 重点政策解读
3. 对公司业务影响
4. 建议关注事项
5. 政策链接清单
