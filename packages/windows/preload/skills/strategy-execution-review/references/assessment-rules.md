# Assessment Rules

Status categories:

- 正常推进
- 存在偏差
- 明显滞后
- 材料不足
- 口径不清
- 需人工确认

High-risk triggers:

- Key annual target behind schedule.
- No evidence for claimed completion.
- Conflicting progress data.
- Responsibility unclear.
- Cross-unit dependency unresolved.
- Final score or accountability would be affected.
