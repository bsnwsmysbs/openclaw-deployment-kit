# Management Optimization Quantification

## Operating Position

Use this skill after one or more scenario outputs already exist. It synthesizes evidence into optimization suggestions and quantification drafts.

Do not ask the client to configure metrics. Use available outputs; if data is missing, mark the metric as `暂不具备量化条件`.

## Default Case Folder

```text
OpenClaw工作台/03-任务现场/公司优化量化/
  01-输入资料/
  02-场景输出汇总/
  03-量化指标/
  99-输出结果/
```

## Workflow

1. Collect reports, ledgers, risk lists, policy briefs, HR analyses, and strategy reviews.
2. Extract repeatable problems, improvement actions, responsible units, and measurable indicators.
3. Separate internal reference conclusions from external presentation claims.
4. Generate optimization report, indicator table, external quantification draft, and evidence index.
5. Put unsupported metrics, sensitive claims, and external statements into human review.

## Required Outputs

```text
99-输出结果/
  公司管理优化建议报告.docx
  对内管理参考清单.xlsx
  对外量化展示指标表.xlsx
  证据来源索引.md
  人工复核清单.xlsx
```

## Boundaries

Do not invent data, claim ROI without basis, compare externally without evidence, or publish sensitive internal risks. External materials must be reviewed by leadership/legal/brand owner.
