# OpenClawMeeting 资料源索引

本索引用于指导用户在桌面中文目录放置资料，并帮助 OpenClaw 在不同功能之间查找材料。

## 总原则

- 用户只需要关注桌面上的 `龙虾工作台`。
- 合同资料单独存放，避免与其他管理材料混在一起。
- 除合同外，其余六类功能默认共用 `综合资料源`。
- 如需更严格归档，也可以使用各功能自己的中文目录。
- 生成的报告、台账、清单、简报和汇报材料统一放到 `桌面\龙虾工作台\02-输出成果`。
- 默认输出 WPS 可打开的 `.docx`、`.xlsx`、`.pptx` 或 `.txt`，不输出 `.md` 文件。

## 默认资料入口

| 类型 | 默认资料目录 | 适用功能 |
| --- | --- | --- |
| 综合资料源 | `桌面\龙虾工作台\01-输入资料\综合资料源` | 会议督办闭环、政策简报、人力绩效分析、战略执行复盘、员工行为分析、管理优化量化 |
| 合同资料 | `桌面\龙虾工作台\01-输入资料\合同资料` | 合同风险审查 |

## 建议文件命名

为了方便检索，建议资料文件名包含日期、部门或主题，例如：

- `2026-06-会议督办-总经理办公会纪要.docx`
- `2026-06-战略执行-重点任务进展.xlsx`
- `2026-06-HR绩效-部门月度数据.xlsx`
- `2026-06-政策简报-综合能源政策材料.docx`
- `2026-06-员工行为-合规流程记录.xlsx`
- `2026-06-合同-采购合同-供应商A.docx`

## 用户提问示例

- `请查看综合资料源，生成会议督办台账和闭环报告。`
- `请基于综合资料源，生成战略执行复盘和偏差预警。`
- `请基于综合资料源，输出部门绩效分析和异常波动提示。`
- `请查看合同资料，输出合同风险条款清单和修改建议。`
- `请列出当前支持的功能和资料放置位置。`
