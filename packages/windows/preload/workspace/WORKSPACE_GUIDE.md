# OpenClawMeeting 使用导航

把资料放到桌面的中文工作台目录，然后在聊天窗口直接用自然语言提问。

默认工作台：

```text
桌面\龙虾工作台
```

## 资料放置

- 除合同外，会议、政策、人力绩效、战略执行、员工行为、管理优化资料都可以先放到：`桌面\龙虾工作台\01-输入资料\综合资料源`
- 合同资料单独放到：`桌面\龙虾工作台\01-输入资料\合同资料`
- 如果希望按业务分开，也可以放到 `会议督办`、`政策简报`、`人力绩效`、`战略执行`、`员工行为`、`管理优化` 等中文目录。

## 功能入口

| 功能 | 材料放置目录 | 示例提问 | 默认产出目录 |
| --- | --- | --- | --- |
| 会议督办闭环 | `桌面\龙虾工作台\01-输入资料\综合资料源` 或 `会议督办` | 请生成会议督办台账和闭环报告。 | `桌面\龙虾工作台\02-输出成果\会议督办` |
| 合同风险审查 | `桌面\龙虾工作台\01-输入资料\合同资料` | 请输出合同风险条款清单和修改建议。 | `桌面\龙虾工作台\02-输出成果\合同审查` |
| 政策简报 | `桌面\龙虾工作台\01-输入资料\综合资料源` 或 `政策简报` | 请生成领导阅示版政策简报。 | `桌面\龙虾工作台\02-输出成果\政策简报` |
| 人力绩效分析 | `桌面\龙虾工作台\01-输入资料\综合资料源` 或 `人力绩效` | 请生成部门绩效分析和异常波动提示。 | `桌面\龙虾工作台\02-输出成果\人力绩效` |
| 战略执行复盘 | `桌面\龙虾工作台\01-输入资料\综合资料源` 或 `战略执行` | 请生成战略执行复盘和偏差预警。 | `桌面\龙虾工作台\02-输出成果\战略执行` |
| 员工行为分析 | `桌面\龙虾工作台\01-输入资料\综合资料源` 或 `员工行为` | 请生成员工行为趋势和合规风险提示。 | `桌面\龙虾工作台\02-输出成果\员工行为` |
| 管理优化量化 | `桌面\龙虾工作台\01-输入资料\综合资料源`，以及各功能产出目录 | 请汇总形成管理优化建议和量化指标草案。 | `桌面\龙虾工作台\02-输出成果\管理优化` |

## 输出格式

- 报告、简报、审查意见：`.docx`
- 台账、清单、统计表、引用索引、日志：`.xlsx`
- 汇报材料、领导版展示：`.pptx`
- 简短操作说明：`.txt`

默认不输出 `.md` 文件，方便用户直接用 WPS 打开。

## 注意事项

- 本交付默认只测试本机访问。
- 不处理会议视频、音频、OCR、转写。
- 合同、HR、员工行为、管理量化等结果均为内部参考草案，需要人工复核。
