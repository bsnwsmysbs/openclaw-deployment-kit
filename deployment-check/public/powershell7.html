安装 PowerShell 7

这份指南可以直接双击 HTML 打开，无需先启动检查台。适用于 Windows x64 新电脑。

  1. 在 Windows 开始菜单打开“命令提示符”或系统自带的 Windows PowerShell。
  2. 执行下面的命令，按提示接受协议并完成安装：
winget install --id Microsoft.PowerShell --exact --source winget

如果提示没有 winget，请打开 微软官方安装说明 ↗，下载稳定版 x64 MSI 并运行安装；安装选项中启用“添加到 PATH”。

  1. 关闭并重新打开终端，再验证版本：
pwsh --version

显示 PowerShell 7.x 即可。如果找不到命令，确认安装完成，或从开始菜单打开“PowerShell 7”后重试。

  1. 回到解压后的仓库，双击 deployment-check\start.cmd，浏览器将打开本机检查台。
  2. 运行全面自检，Node.js/npm 缺失、过旧或无法运行时会自动通过 winget 安装；若弹出系统授权窗口，请允许安装。检查通过后点击“安装仓库自带轻量版”完成部署。

Windows 自带的 PowerShell 5.1 仍会保留，请使用新安装的 PowerShell 7。
