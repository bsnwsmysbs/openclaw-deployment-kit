⊞ Windows 本机
STEP 0 · POWERSHELL 7

新电脑先安装 PowerShell 7

已安装可以跳过。首次安装时，在 Windows 开始菜单打开“命令提示符”或系统自带的 Windows PowerShell，执行：

winget install --id Microsoft.PowerShell --exact --source winget

按提示完成安装后，关闭并重新打开终端，执行 pwsh --version，应显示 PowerShell 7.x。然后双击 deployment-check\start.cmd 打开检查台。

没有 winget？按 微软官方安装说明 ↗ 下载稳定版 x64 MSI，安装时启用“添加到 PATH”。Windows 自带的 PowerShell 5.1 需要另行安装 7。

DEEPSEEK · API KEY
补填／修改 SK 密钥
安装时没填，或需要更换 Key？在这里保存到上方目录的已有安装。保存前会备份旧启动文件，保存后检查密钥和模型。
密钥保存在本机启动配置，不回显到网页或报告。若网关正在运行，保存后需先运行安装目录的 stop-gateway.cmd，再运行 start-gateway.cmd，让新密钥生效。
